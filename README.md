# Arcane Archive v12 — Dark Souls II routes

Обновлена стандартная сборка `ds2-knight-power`: маршруты А/Б, уровни 13–130, финальная пара Искривлённый меч + Чёрная катана, этапы оружия и чек-лист.

## Обновление GitHub
Заменить `js/data.js`, `js/core.js`, `js/cloud.js`, `js/views.js`, `css/styles.css` с сохранением структуры папок. **Не заменять `js/site-config.js`**, он содержит текущий публичный ключ Supabase. После публикации обновить страницу (Ctrl+F5), проверить маршруты, затем вручную синхронизировать. Сначала скачать резервную копию JSON.

## Данные
Рассчитаны по стартовым характеристикам рыцаря 13-го уровня. Оба маршрута используют одну и ту же карточку и один чек-лист. При миграции стандартного билда переносятся галочки известных задач. Сложные пользовательские изменения стандартной сборки следует предварительно экспортировать и проверить: обновление намеренно заменяет стандартные рекомендации.

Сайт статический и не требует изменений в Supabase SQL.
